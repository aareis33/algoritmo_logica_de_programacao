# algoritmo_logica-de-programacao

Repositório destinado aos estudos e exercícios desenvolvidos durante o curso de Algoritmos e Lógica de Programação (40 horas).

Conteúdos estudados

Introdução aos algoritmos e primeiros programas
Comandos de entrada e operadores
Operadores lógicos e relacionais
Introdução ao Scratch
Resolução de exercícios com algoritmos
Estruturas condicionais
Estruturas de repetição
Procedimentos e funções
Vetores e matrizes

Objetivo

Desenvolver o raciocínio lógico e construir uma base sólida para aprender linguagens de programação e resolver problemas computacionais.

Este repositório registra minha evolução e prática durante o aprendizado.
